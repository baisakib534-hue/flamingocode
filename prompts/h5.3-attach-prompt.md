## H5.3 @-attach in chat (Hermes §23)
In the chat input, typing @ opens a picker (files, folders, the
current diff, a URL) and attaches it to the prompt, so he can say
"fix @this file" or "follow @this doc" without pasting paths.
The attached thing shows as a chip, removable with one tap. This
is a USER affordance for CONTEXT — never a tool mention: the
agent still decides which skill/plugin/MCP to use by itself
(the autonomy rule stands). Size S. Web: yes.
