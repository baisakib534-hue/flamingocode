What Is FlamingoCode?

FlamingoCode is a local-first agentic coding studio. You run it on your machine — no cloud, no external servers for your code. It gives you a team of AI agents that can plan, write, test, and review code together.

Key principles:

  • Local-first: Your code never leaves your machine. The desktop app runs entirely locally.
  • Agent teams: Multiple specialized agents (Senior Dev, Frontend, Backend, QA) collaborate on tasks.
  • Shared Brain: Persistent project memory across sessions — agents remember decisions and patterns.
  • Phone companion: Review and approve tasks from your phone via the relay.
  • Your keys, your control: API keys are encrypted device-to-device. The relay passes opaque envelopes only.

Quickstart (Desktop)

  1. Download the desktop app for your OS from the Download page.
  2. Run the binary — no installation required (Windows/macOS/Linux).
  3. Sign in with your Google account. This creates your FlamingoCode account.
  4. Add an API key in Settings → Providers. Choose from presets (9router, OpenRouter, Groq, Ollama, etc.) or add a custom OpenAI-compatible endpoint.
  5. Create or pick an agent — use the built-in "Dev Team" preset or create your own.
  6. Start coding — describe what you want in the chat. Your agent team will plan, execute, and test.

Phone Pairing

The phone companion lets you review tasks, approve changes, and monitor agent activity from anywhere.

How Pairing Works

  1. Sign in to the Account page on this website with the same Google account used on desktop.
  2. Install the FlamingoCode phone app (Android) and sign in with the same Google account.
  3. Both devices register with the relay automatically. You'll see them listed on the Account page.
  4. When a task runs on desktop, you'll get a notification on your phone to review/approve.

What the Relay Does

  • Registers devices to your account (device ID, name, type, last seen)
  • Passes task envelopes between devices (opaque — relay cannot read contents)
  • Handles long-polling for task delivery (up to 25s per request)
  • Stores task results and recording links

All communication is authenticated with a session token issued at sign-in. Tokens are stored hashed (SHA-256) in the relay's datastore.

Agent Teams

FlamingoCode's team mode runs multiple agents in a structured workflow:

  1. Discussion: Agents exchange messages to propose a task split.
  2. Planning: Senior Developer finalizes a task board (task → owner agent).
  3. Execution: Agents work in parallel (independent) or sequence (dependent).
  4. Presentation: Each agent presents its completed piece.
  5. Testing: The team runs tests (click every button, sweep console errors).
  6. Senior Review: Senior inspects all work, names bugs, assigns rework (max 3 rounds).
  7. Final Report: Summary of what was built, who did what, test results.

You can create custom agents with any provider+model, attach skill packs (No AI Slop, Senior Frontend, Testing & QA, etc.), and define MCP servers.

  • Custom: Any OpenAI-compatible or Anthropic endpoint

Key Handling

API keys are stored locally in the desktop app's encrypted storage. When sending a task to a paired device, keys travel inside an encrypted envelope using a per-pair key derived at pairing time. The relay never sees raw keys.

FAQ

Is my code sent to the cloud?

No. The desktop app runs entirely on your machine. Only task envelopes (which you control) pass through the relay. The relay cannot decrypt them.

Do I need an API key?

Yes, for LLM calls. You can use free tiers (Pollinations, DuckDuckGo AI) or bring your own keys (OpenRouter, Groq, OpenAI, Anthropic, local Ollama).

What happens if the relay is down?

Desktop app works fully offline. Phone pairing and task relay require the relay. The relay is hosted on Vercel's free tier with 99.9% uptime SLA.

Can I self-host the relay?

The relay is a set of Vercel serverless functions. You can deploy your own copy to any Vercel account — just set the environment variables.

Is there telemetry or analytics?

No. Zero analytics, zero trackers. The only data stored is your account (Google email/name), device registry, and task envelopes you explicitly send.

What's the license?

FlamingoCode is proprietary. The desktop app binary is free to download and use. Source code is not open source at this time.

Relay API Reference

For developers building integrations. All endpoints require Authorization: Bearer .

Devices

POST /api/devices/register
  { name, type: 'desktop'|'phone', pushToken? }
  → { deviceId, pairCode }

GET /api/devices
  → [{ deviceId, name, type, lastSeen }]

DELETE /api/devices/:id
  → { ok: true }

Tasks

POST /api/tasks
  { toDeviceId, envelope }
  → { taskId }

GET /api/tasks/poll?deviceId=
  → [{ taskId, envelope }]  (long-poll, up to 25s)

POST /api/tasks/:id/result
  { result }
  → { ok: true }

GET /api/tasks/:id
  → { taskId, toDeviceId, envelope, result, status, createdAt }

Recordings

GET /api/recordings/:id
  → { url }  (signed link, expires in 1 hour)
